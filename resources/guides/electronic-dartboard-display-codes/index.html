Electronic dartboard display codes, decoded

In a DAYIN model name, the display code has a number and a letter. The number tells you what the display shows; the letter tells you how it is made. In WDH2-54S, 54 means 1 current score + 4 player scores + 4 cricket readouts, and S means a flexible-light LCD with illuminated digits. See them on cabinet dartboards.

The number: what is shown

  • First digit = score readouts. An even digit is the number of player scores; an odd digit means the extra 1 is the current score - the score of the dart just thrown.
  • Second digit = the number of cricket readouts.

The letter: how it is made

CLCD
SFlexible-light LCD, illuminated digits
LBacklit LCD
ELED seven-segment

Full-LCD layouts (82, 89, 92, 95, 99) have their own screen size and layout and do not follow the rule above. They are available as standard, backlit or flexible-light LCD; LED seven-segment cannot render a full layout.

OX means the cricket readouts are built into the door panel at a larger size; they count in the second digit and are not repeated on the body. The number of players a machine supports is set by its software, not by the display.

FAQ

Questions, answered.

Does a “20” display limit the number of players?

No. The number of players is set by the software. A 20 display shows two scores at a time, and the machine still runs multi-player games.

Can I choose a different display for a model?

Yes. Display type and layout are part of the OEM options and can be specified.
